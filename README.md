## 🏛️ عن البوابة (Overview)

تمثل هذه البوابة الواجهة الرقمية الرسمية لـ **إدارة الشراء الموحد وتأمين السلع الاستراتيجية** التابعة لـ **جهاز مستقبل مصر للتنمية المستدامة**. تتولى الإدارة هندسة الصفقات والتعاقدات السيادية والتجارة الدولية لتأمين المخزون الاستراتيجي للدولة المصرية (القمح، الذرة، الصويا، الزيوت، السكر، الأرز، اللحوم والرؤوس الحية، والجمبري)، بالتنسيق المباشر مع الوزارات والجهات المعنية، وإدارة الخدمات اللوجستية للموانئ والصوامع وتوزيع السلع محلياً.

## ✨ المميزات الرئيسية (Core Features)

* **🏢 الهيكل التنظيمي التخصصي (Executive Directorates):** استعراض شامل للقطاعات الـ 8 التنفيذية (التعاقدات الدولية، التوريد المحلي، سلاسل الإمداد، المخزون، الشؤون القانونية، المالية، التجارة الداخلية).
* **📅 جدول لجان البت والتوريد الأسبوعية (Weekly Committees Schedule):**
  * **الأحد (02:00 ظهراً):** لجنة الأرز (الأولوية بأسبقية التواجد).
  * **الثلاثاء (02:00 ظهراً):** لجنة الرؤوس الحية (نظام أسبوعي تبادلي).
  * **الاثنين (02:00 ظهراً):** لجنة الجمبري (نظام أسبوعي تبادلي).
* **🤖 المساعد الذكي التفاعلي (Interactive AI ChatBot):** استعلام فوري عن اللجان، شروط التوريد، مواعيد العمل الرسمية، وحزم المناقصات.
* **🔍 البحث الفوري الذكي (Quick Search - Ctrl+K):** محرك بحث محلي وسريع في كافة أقسام وإدارات وخدمات البوابة.
* **🌐 دعم متعدد اللغات (Multilingual RTL/LTR):** دعم كامل للغات (العربية، الإنجليزية، البولندية، الأوكرانية).
* **🌓 الوضع الليلي والنهاري (Dark/Light Mode):** مظهر فاخر بتدرجات ذهبية وميكانيكية تلائم الهيئات السيادية.
* **📱 تصميم متجاوب فائق الدقة (Fully Responsive):** متوافق بنسبة 100% مع الهواتف الذكية، الأجهزة اللوحية، وشاشات سطح المكتب.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** React 19 + Vite 8
* **Styling:** Tailwind CSS v4 + PostCSS
* **Icons:** Lucide React
* **State & Data:** Centralized Data Architecture (`portalData.js`)

## 🚀 التشغيل والتطوير المحلي (Quick Start)

```bash
# 1. تثبيت الحزم (Install dependencies)
npm install

# 2. بدء السيرفر المحلي (Start local development server)
npm run dev

# 3. بناء نسخة الإنتاج (Build for production)
npm run build

# 4. معاينة نسخة الإنتاج (Preview production build)
npm run preview
```
